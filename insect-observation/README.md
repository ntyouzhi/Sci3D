# 昆虫观察

与 `bird-observation` 共用浅绿色视觉风格：顶部昆虫切换、中央三维观察、右侧控制与观察提示。

动态观察顺序固定为蚂蚁、蜜蜂、蝴蝶、萤火虫。界面只保留观察文字，英文模型副标题和制作信息不在主界面显示，来源与处理说明留在本文件和来源文件中。静态模型缓存数据保持只读，每次显示复制坐标与索引后再变换，避免切回后累积旋转和着色区域错误；切换默认恢复着色、关闭线框及标注，并回到立体视角。`tools/verify-insect-switches.cjs` 分别验证在线和离线的反复切换，返回画面与初始画面一致。本次只更新界面版本，不改模型资源缓存版本，已有模型缓存继续复用。

萤火虫当前动作链为地面弹跳一次、扇翅飞起、平稳悬停8秒、缓缓落地。已移除源动作中身体主骨骼的跳跃位移与姿态，身体高度只由单次地面弹跳和平滑飞行轨迹控制，飞行中不再反复弹跳。`tools/verify-firefly-flight-height.py` 验证地面弹跳次数与悬停高度稳定性。

萤火虫收翅顺序：先打开鞘翅，内翅整片平滑转出；落地后用1.8秒向后转回鞘翅下，再合上鞘翅。已移除翅尖对折关节，恢复原膜翅网格与蒙皮。翅膀始终保持原尺寸，不通过缩小、隐藏或透明度变化收翅。这是简化的教学舒展示意，不复现或推定该物种的真实膜翅折痕结构。

鞘翅展开时同时向外和向上避让，内翅扇幅限制为12度。内翅转向与伸展分阶段进行，鞘翅完全打开后才伸展；内翅收纳完成后鞘翅才关闭。`tools/check-firefly-wing-clearance.py -- --verify` 检查501个采样帧的鞘翅与内翅三角面相交，当前循环未检测到相交。

蝴蝶直接播放24秒连续循环：地面扇翅 → 起飞 → 空中悬停 → 缓缓落地。全部阶段在同一动画中，暂停和慢放不会打断流程。页面不再提供动作选择和手动落地按钮；历史单独动作仍保留在资源中。重建连续动作时，先运行 `tools/export-butterfly.py`，再运行 `tools/build-butterfly-continuous.py` 与 `tools/build-butterfly-embed.cjs`。

当前为蜜蜂原始骨骼动画、萤火虫悬停落地示意、黑色蚂蚁爬行动画、蝴蝶连续起落示意与五个静态观察入口。瓢虫只保留新的“七星瓢虫”原材质模型；原示意着色瓢虫入口已移除，旧链接自动转到新模型。旧资源文件保留，不再从页面加载。

蜜蜂来自用户提供的 `蜜蜂/uploads_files_3053075_honeybee-animation-eeveerender.blend`。网页保留原57骨骼和0–417帧动画（30fps），不导出相机、灯光、粒子毛发或3.79GB Alembic缓存。身体颜色贴图缩至1024，翅膀与细节贴图缩至512；身体使用不透明材质，翅膀保留透明贴图。GLB约1.31MB，网络gzip约1.07MB；仅选中时下载。共享浏览组件另约0.29MB，只下载一次。重建用 `tools/export-bee.py` 和 `node tools/build-ladybug-embed.cjs bee`。原文件不改动。

资源缓存有效期为下载后30天，使用时检查到期；页面加载时清理当前版本过期条目及本应用旧版本缓存，不清理其他应用缓存。切换昆虫、刷新和重新打开同源网页可复用有效缓存；升级版本后重取资源。浏览器隐私模式、用户清理数据或存储空间不足可能使缓存提前失效，不能保证一定保存30天。首次加载时间取决于网速与设备，不等于缓存有效期。缓存校验见 `tools/verify-bee.cjs`。

本地模拟2Mbps下载、100ms延迟时，蜜蜂冷启动（含共享组件）约6.6秒，有效缓存后刷新约0.9秒。这是本机测试，不是实际GitHub访问时长保证。网页实际需要下载约1.07MB模型与首次约0.29MB共享组件，不下载源Blend、贴图原图或Alembic文件。

七星瓢虫来自用户提供的 `A491萤火虫/七星瓢虫4.2.0.blend`。源文件有绑定但无动画，本次只展示源姿态，不新增运动。网页副本将六个UDIM贴图区分成独立材质并恢复各区UV；保留红黑斑纹、白色胸部标记、法线和粗糙度贴图。约29386个三角面，GLB约1.91 MB，网络gzip约1.50 MB，选中时加载，支持离线双击观察。原文件不改动。重建使用 `tools/export-ladybug.py` 与 `tools/build-ladybug-embed.cjs`。源文件名称不作为物种鉴定依据，公开分发许可待确认。

萤火虫来自用户提供的 `A491萤火虫/luciola-lateralis-japanese-fire-fly.blend`，基于原骨骼与姿态制作20秒连续起落教学示意：地面停留、展开鞘翅起飞、空中悬停约8秒、约3秒缓缓落地、收翅停留后重复。保留六张贴图和腹部发光材质，加入固定淡色地面参照，镜头不随高度重新居中。网页副本将贴图限制到1024像素并采用90质量JPEG编码；原文件不改动。模型约1.44 MB，网络gzip约0.92 MB，选中时才下载，返回时使用缓存。动作与发光不是实测飞行、强度或节律，不额外添加闪光动画。重建使用 `tools/export-firefly.py`、`tools/build-firefly-embed.cjs`；源模型作者及公开分发许可尚未确认。

蝴蝶来自用户提供的“A-6蝴蝶+材质+绑定”资源。FBX包含骨骼但没有动画；本页利用原骨骼制作地面扇翅、空中悬停、小步走动三个6秒循环，另有6秒的一次性缓缓落地动作。落地结束自动切回地面扇翅。保留四张原始贴图，增加翼尖柔曲、前后翅延迟和幅度变化；悬停时身体轻微起伏、足稍收拢，下落过程中足逐渐展开。走动使用足部支撑目标并加入触角和头部轻摆。只对网页副本细分翅膀、调整权重并加入轻淡的固定地面参考；用户源文件未改动。FBX转换丢失的材质分组和UV已从同套OBJ恢复。动作不是实测数据，尚未核实模型的物种、悬停能力与公开分发许可。

## GitHub Pages 使用

确认模型公开分发权限后，将整个 `insect-observation` 文件夹放到网站仓库中，保持目录结构。入口为 `insect-observation/index.html`。不需要后台，不依赖外部 CDN，仓库子路径也可使用。这里只准备和验证文件，没有执行上传或发布。

网络访问只加载当前昆虫。蚂蚁使用轻量页面 `animations/ant-web.html`、压缩动画与运行组件，首个动画不加载静态模型组件。静态模型使用 `models/*.bin.gz`。压缩数据由浏览器解压，不依赖网站服务器的压缩配置。资源缓存采用版本化 Cache Storage；加载失败不保存，重新点击可重试。新资源发布时需同步修改 `asset-loader.js` 中的缓存版本与页面版本号。

桌面/平板按屏幕大小显示，三维渲染像素倍率上限为 1.5，隐藏页面暂停静态渲染。切换到静态对象时卸载动画，不让后台动画占用显卡。

本地双击 `index.html` 仍可离线使用。`models/*.js`、`vendor/three.js` 与 `animations/ant.html` 是本地文件模式和旧浏览器的兼容资源；网络版现代浏览器不下载这些大文件。请勿只上传 HTML。
